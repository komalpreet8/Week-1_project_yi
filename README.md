# Week 1 Task: Transforming Wireframes into Static Web Pages

## 📌 Project Overview

This project is part of my Frontend Development Internship. The objective is to create a static webpage using HTML5 and CSS3, focusing on webpage structure, styling, layout, and responsive design.

## 🎯 Objectives

- Convert a basic design concept into a static webpage.
- Understand semantic HTML elements.
- Apply CSS styling for an attractive layout.
- Use Flexbox to arrange webpage elements.
- Implement responsive design using CSS media queries.
- Test the webpage on different screen sizes.

## 🛠️ Technologies Used

- *HTML5* – To create the webpage structure.
- *CSS3* – To style and design the webpage.
- *Visual Studio Code* – To write and edit the code.
- *Web Browser* – To run and test the webpage.

## ✨ Features

- Clean and simple user interface.
- Header with navigation links.
- Hero section with a heading and button.
- Content section describing the project.
- Service cards for displaying information.
- Footer section.
- Responsive layout for smaller screens.
- Organized and semantic HTML structure.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Locate the index.html file.
4. Double-click index.html to open it in your web browser.
5. Resize the browser window to check the responsive layout.

No additional software or dependencies are required apart from a web browser and a code editor.

## 📱 Responsive Design

CSS media queries are used to adjust the webpage layout for smaller screens. Flexbox and flexible widths help maintain proper alignment and improve usability across different screen sizes.

## 📚 Learning Outcomes

Through this task, I learned how to structure a webpage using semantic HTML, style elements using CSS, arrange content with Flexbox, and create responsive layouts using media queries. I also gained practical experience in organizing project files and testing a webpage in a browser.
